# BAP Test Site

A fast, accessible single-page concept for the Beta Alpha Psi Kappa Lambda chapter at Southern Illinois University Edwardsville.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

## Deployment

The production build is published from the `gh-pages` branch:

https://adamnolle.github.io/BAP-Test-Site/
